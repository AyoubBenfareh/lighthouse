## General integrity

- [ ] No invented Quran verses, hadith, or fabricated source citations
- [ ] No depictions of Allah, prophets, or angels in art or copy
- [ ] Sacred material is not used as decorative collectibles
- [ ] Stars / XP are clearly educational rewards only (not spiritual merit)
- [ ] No awards for claiming to have performed real religious obligations
- [ ] Encouraging feedback only — no shaming language on incorrect answers
- [ ] Age-appropriate for 6–10; minimal required reading where possible

## Arabic letters

- [ ] Letter names and sample words are correctly vowelled where shown
- [ ] Object–letter associations are pedagogically sound for beginners
- [ ] Diacritics render without clipping in Arabic UI
- [ ] Optional speech uses ordinary vocabulary only (not Quran)

## Wudu sequence

- [ ] Sequence is acceptable as a **commonly taught introductory** teaching order
- [ ] In-app disclaimer remains: learning activity, not a validity ruling
- [ ] Obligatory vs recommended acts are not conflated as universal facts
- [ ] Jurisprudential differences (madhhab) are flagged where relevant
- [ ] Wording does not declare a child's real wudu valid/invalid

## Good manners

- [ ] Scenarios reflect widely taught Islamic manners (akhlaq)
- [ ] “Correct” choices are clearly kind/honest/respectful without sectarian framing
- [ ] Incorrect choices receive supportive redirection, never humiliation
- [ ] Parental respect / honesty / sharing / cleanliness / helping are accurate themes

## Localization (ar / de / en)

- [ ] Arabic copy is natural and respectful
- [ ] German and English educational phrasing is clear for children
- [ ] RTL layout reviewed on Arabic language setting
- [ ] Mixed RTL/LTR (Arabic letters inside EN/DE UI) checked

## Privacy & child safety (product, for awareness)

- [ ] Offline-first; no child accounts; no ads; no chat/social
- [ ] Parent gate present before parent settings / external-link affordances
- [ ] No Quran TTS / AI chat for children
